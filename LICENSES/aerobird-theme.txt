MODIFICATIONS BY THE PARISHBSD PROJECT
--------------------------------------

The following modifications were made to the upstream theme to
ensure compatibility with XFCE 4.20 on FreeBSD. Under GPL v3 §5(a),
these modifications are marked and dated.

    2026-10-07
        Reordered @import statements in gtk.css so that color
        palette definitions (colors.css, colors-themed.css)
        precede widget rules. Fixes theme application under XFCE
        4.20, where a color referenced before its definition
        resolves to transparent.

    2026-10-07
        Added gtk-4.20-fixes.css, containing selectors for
        components whose internal widget structure changed between
        XFCE 4.18 and 4.20: Thunar sidebar, panel background, CSD
        headerbars, notification window, list rows.

    2026-10-09
        Generated index.theme for each theme variant. The upstream
        archive does not include this file, which is required by
        lxappearance and some other theme tools.

    2026-10-10
        Removed the @import for progress-bars.css. The referenced
        file is not present in the upstream archive; the import
        fails silently in some GTK versions and produces warnings
        in others.

The modifications are applied automatically by the ParishBSD
installation script (15-setup-desktop.sh) from the patch files in
host/themes/patches/. The upstream archive at host/themes/ is kept
unmodified.

These modifications are released under the same license as the
original theme (GPL v3), as required by the license.
